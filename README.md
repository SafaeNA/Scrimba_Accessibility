# Scrimba_Accessibility
**Resource:** [Learn Accessibility – Scrimba](https://www.v1.scrimba.com/learn/accessibility)

### 1. What accessibility enhancements were the most challenging to implement, and why?

The most challenging part was making sure users could navigate the website using only a keyboard and adding proper descriptions to images and buttons. I had to make sure the website was easy to use for everyone, including people who use screen readers. It also took some extra testing to make sure everything worked correctly without affecting the website's design.

### 2. How do ARIA attributes improve the experience for users relying on assistive technologies?

ARIA attributes help screen readers better understand the different elements on a website. They provide extra information about buttons, menus, and forms. For example, `aria-label` can explain what a button does, while `aria-expanded` tells users whether a menu is open or closed. This makes it easier for people using assistive technologies to navigate and interact with the website.

### 3. What tools did you use to check color contrast, and how did they help?

I learned about tools like WebAIM Contrast Checker and WAVE Accessibility Evaluation Tool, which help identify accessibility issues, including poor color contrast. These tools can check if the text and background colors have enough contrast to make the content easy to read. They are especially helpful for people with visual impairments and help developers make their websites more accessible.
